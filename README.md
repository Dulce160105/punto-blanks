# PUNTO BLANKS

Sistema de ventas, caja, inventario, cuentas por cobrar/pagar, gastos y reportes.
Web estática (GitHub Pages) + base de datos y login en Supabase.

- `index.html` — la aplicación
- `config.js` — URL y clave **publishable** de Supabase (públicas)
- `supabase/schema.sql` — tablas, seguridad (RLS) y respaldos
- `GUIA.md` — guía paso a paso para publicarla gratis

Lea **GUIA.md**.
