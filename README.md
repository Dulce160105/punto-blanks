# PUNTO BLANKS

Sistema de ventas, caja, inventario, catálogo con fórmulas, cuentas por cobrar/pagar, gastos y reportes.
Web estática (GitHub Pages) + base de datos y login en Supabase (opcional).

- `index.html` — la aplicación
- `config.js` — URL y clave **publishable** de Supabase (públicas)
- `vendor/supabase.js` — biblioteca de Supabase (incluida, sin CDN)
- `supabase/schema.sql` — tablas, seguridad (RLS) y respaldos
- `GUIA.md` — guía paso a paso para publicarla gratis
- `AUDITORIA.md` — informe de auditoría (hallazgos, correcciones y pruebas)

Lea **GUIA.md**.
